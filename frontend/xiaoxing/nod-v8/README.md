# 小星逐帧点头 · v8

用户选择了二维连续画面，本次用内置 imagegen 重新绘制点头帧。没有使用外部视频生成任务、3D 模型或新增联网服务。

## 画面与播放

以原画头部裁切的九宫格为参照，生成保持同一人物、画风和构图的连续图。筛选前六张头部画面，保留原画作为首尾；播放顺序为原画、0、1、2、3、4、5、4、3、2、1、0、原画，共 13 个画面位置。绘制段长约 1.48 秒，结束后保留 0.16 秒中性姿态再交回原有交互。

WebP 仅包含真正使用的头部区域。制作时统一裁切、羽化合成边界并打包，没有通过代码生成或扭曲点头姿势。脸部姿态来自生成的图，身体、手、衣服、月亮保留原图。整个头部不是三维结构，细小的发丝和面部仍可能有逐帧插画差异。

原图：../artwork/ 中既有角色原画；运行时原画 static/images/sharehub-muse-800.webp。
本次生成源图：nod-atlas-generated.png。
原画裁切：head-reference.png。
严格对齐参照：registered-template.png。
完整提示词、参考角色和选用输出：prompts.json。
生成方式：内置 image_gen，未使用 CLI/API fallback。
生成后的裁切和打包：build-assets.cjs。

## 网页接入

- 全站共用 _avatar.html 增加“轻轻点头”，六个动作恢复两行三列。
- static/js/xiaoxing-nod.js 用 Canvas 2D 绘制帧图。显式点击才请求 WebP，加载后同页复用。
- static/images/xiaoxing-nod-atlas-v8.webp 为 1200×640，109446 字节（约 107 KiB），解码像素约 2.93 MiB。
- 点头过程中不提交 WebGL 绘制，仅换帧时重绘 Canvas。二维动作使用独立定时调度，避免依赖旧 WebGL 动作的帧回调。
- 只播放一次，不自动循环点头；连点不重开动作。切换其他动作时完成当前短点头再接续。
- 减少动态偏好下不下载/播放点头。隐藏标签页、离屏、收起角色时停止调度；重新显示后继续。
- 加载失败保持原有角色可用，允许重试。运行时的上下文丢失/销毁处理会清理帧播放器。
- 首页和各页面悬浮角色使用同一实现。其他五个动作仍是已有原画分层交互。

## 检查与回看

review/index.html 可直接打开，支持播放一次、慢速查看和更换深浅背景。浏览器检查与录屏记录在本轮工作目录的 review/，发布清单含最终结果与备份位置。检查覆盖手机布局、全站共享入口、连续回程、重复点击、动作衔接、静态/离屏/收起暂停、失败重试及按需下载。

开发机没有实体 GPU；Chromium 使用 SwiftShader。其 WebGL 渲染可能拖延 requestAnimationFrame，因此测试断言采用独立计时轮询。录制连续画面验证了实际帧序列，测试不是实体手机功耗或刷新率基准。
