## Resource policy

- Character module loads only when visible and allowed by motion settings, or explicitly requested. Mobile floating companions remain collapsed until opened.
- Model transfer: 2,072,870 bytes compressed, with a 5,503,108-byte uncompressed fallback for browsers without DecompressionStream. Bundled runtime: 747,730 bytes before HTTP compression. Existing poster: 71 KB / 161 KB.
- Maximum 30 fps desktop / 24 fps mobile for actions; 12 fps idle. Slow rendering lowers the action cap to 18 fps. Pixel ratio capped at 1.35 desktop / 1 mobile; low-power renderer; no real-time shadows or postprocessing.
- Animation stops offscreen, minimized, hidden, or when the persistent motion control is disabled. Reduced-motion and save-data are respected. Unsupported WebGL falls back to the poster.
- Gallery videos load on deliberate pointer/focus interaction and stop when inactive. Chat previews do not fetch video metadata; background chat and AI queue polling skip hidden pages.
- Measured in headless Chromium software WebGL: 21 draw calls and 70,152 triangles; adaptive cap engaged. These are rendering counters, not real-device battery benchmarks.
